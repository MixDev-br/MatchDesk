# Security

Please report suspected vulnerabilities privately to [MatchDesk support](mailto:efootballtoolkitpro.suporte@gmail.com), with the subject **MatchDesk security report**. This existing support address remains in use during the rebrand.

Include the affected application and version, a description of the issue, its potential impact, and the minimum steps needed to reproduce it. Use test data and redact personal information and credentials.

Do not post vulnerabilities, license keys, passwords, tokens, private keys or customer information in public issues. Do not include executable attachments in an initial report.

New MatchDesk builds are still in preparation. Packages carrying the previous brands have been withdrawn from public distribution; their availability in Git history does not indicate current support. Compatibility and update requirements will be documented with each new release.

Em português: relate vulnerabilidades em particular pelo e-mail acima, com o aplicativo, a versão e os passos mínimos para reprodução, sem expor credenciais ou dados pessoais.

En español: comunica las vulnerabilidades en privado al correo anterior, indicando la aplicación, versión y pasos mínimos para reproducirlas, sin revelar credenciales ni datos personales.
