## Português

**Novas builds em preparação. Nenhum pacote MatchDesk está disponível aqui neste momento.**

As publicações das marcas anteriores foram retiradas. O novo site e os aplicativos MatchDesk serão lançados juntos. A data e as versões serão anunciadas quando os pacotes estiverem prontos.

Os canais oficiais são o [site MatchDesk](https://mixdev-br.github.io/MatchDesk/) e este [repositório](https://github.com/MixDev-br/MatchDesk). As instruções específicas de distribuição serão informadas com cada aplicativo. Quando publicados, os pacotes devem identificar aplicativo, versão e plataforma, com notas e informações de integridade.

Não há um novo manifesto de atualização disponível durante esta transição. Não renomeie pacotes antigos para simular uma versão MatchDesk e não instale arquivos de terceiros. Se você já utiliza uma versão anterior e precisa de ajuda, consulte o [suporte](SUPPORT.md).

## English

**New builds are in preparation. No MatchDesk package is available here at this time.**

Releases carrying the previous brands have been withdrawn. The new website and MatchDesk applications will launch together. Dates and versions will be announced when the packages are ready.

The official channels are the [MatchDesk website](https://mixdev-br.github.io/MatchDesk/) and this [repository](https://github.com/MixDev-br/MatchDesk). Each app will include its distribution instructions. Published packages should identify the app, version and platform, with release notes and integrity information.

No new update manifest is available during this transition. Do not rename older packages to impersonate a MatchDesk release or install third-party copies. If you already use an earlier version and need help, contact [support](SUPPORT.md#english).
