# MatchDesk | Support

## Português

Use o [e-mail de suporte](mailto:efootballtoolkitpro.suporte@gmail.com) para ativação, pagamentos e licenças. Participe também da [comunidade no Telegram](https://t.me/+s2IX0iiXNdFmYzcx).

Para falhas do aplicativo ou sugestões, [abra uma issue](https://github.com/MixDev-br/MatchDesk/issues/new/choose) e informe:

- aplicativo e versão utilizada;
- versão do Windows ou Android, plataforma do jogo e tipo de conexão;
- passos para reproduzir, resultado esperado e resultado observado;
- no OpenWrt, modelo e revisão de hardware do roteador e versão do firmware.

Remova dados pessoais de logs e capturas antes de enviá-los. Nunca publique chave de licença, senha, token, comprovante ou código completo de dispositivo. Envie problemas de segurança em particular, seguindo [SECURITY.md](SECURITY.md).

Consulte [Downloads](DOWNLOADS.md#português) e os guias do [Pro](docs/PRO.md#português), [Scout](docs/SCOUT.md#português) e [Mobile](docs/MOBILE.md#português) para instalar, atualizar e começar a usar.

## English

Contact [support by email](mailto:efootballtoolkitpro.suporte@gmail.com) for activation, payments and licenses. The [Telegram community](https://t.me/+s2IX0iiXNdFmYzcx) is also available.

For bugs and suggestions, [open an issue](https://github.com/MixDev-br/MatchDesk/issues/new/choose). Include the app and version, operating system, game platform, connection type, reproduction steps, and expected and actual results. For OpenWrt, include the router model, hardware revision and firmware version.

Remove personal data from logs and screenshots. Never publish a license key, password, token, payment receipt or complete device code. Report security issues privately as described in [SECURITY.md](SECURITY.md).

See [Downloads](DOWNLOADS.md#english) and the [Pro](docs/PRO.md#english), [Scout](docs/SCOUT.md#english) and [Mobile](docs/MOBILE.md#english) guides for installation, updates and getting started.
